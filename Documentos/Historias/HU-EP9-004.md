# HU-EP9-004: Consultar movimientos de inventario

## Formato estandar

Como **administrador**, quiero **consultar movimientos de inventario** para **auditar cambios de stock y mantener trazabilidad completa**.

---

## Descripcion

El reporte `/reports/inventory-movement-summary` permite consultar movimientos de inventario con filtros obligatorios de fecha, filtro opcional por punto de venta y busqueda por nombre de producto o SKU. El administrador puede elegir el modelo de salida:

- **Resumen:** agrupa los movimientos por producto y muestra adiciones, sustracciones y diferencia.
- **Detalle:** muestra cada movimiento de inventario individual con fecha, tipo, producto, SKU, punto de venta, cambio, cantidades antes/despues, usuario, motivo, venta asociada y devolucion asociada.

La exportacion a Excel respeta el modelo de salida seleccionado y mantiene el limite maximo de 50.000 filas.

---

## Criterios de Aceptacion

### Escenario 1: Consultar resumen con filtros
**Dado que** existen movimientos de inventario  
**Cuando** consulto el reporte con fechas obligatorias y modelo **Resumen**  
**Entonces** veo una lista paginada agregada por producto  
**Y** veo producto, SKU, adiciones, sustracciones y diferencia

### Escenario 2: Consultar detalle con filtros
**Dado que** existen movimientos de inventario  
**Cuando** consulto el reporte con fechas obligatorias y modelo **Detalle**  
**Entonces** veo una lista paginada de movimientos individuales ordenados por fecha descendente  
**Y** veo fecha, tipo, producto, SKU, punto de venta, cambio, antes, despues, usuario, motivo, venta y devolucion

### Escenario 3: Buscar por producto o SKU
**Dado que** existen movimientos de varios productos  
**Cuando** ingreso texto en el filtro de producto o SKU  
**Entonces** el reporte incluye solo movimientos cuyo producto o SKU coincide con la busqueda  
**Y** el filtro aplica tanto al resumen como al detalle

### Escenario 4: Exportar el modelo seleccionado
**Dado que** consulte el reporte en resumen o detalle  
**Cuando** exporto a Excel  
**Entonces** el archivo descargado contiene columnas acordes al modelo seleccionado  
**Y** si hay mas de 50.000 filas se muestra una advertencia para ajustar filtros

---

## Tareas

1. Backend: Endpoint `GET /api/reports/inventory-movements` con modelos `summary` y `detail`, busqueda por producto/SKU y paginacion.
2. Backend: Endpoint `GET /api/reports/inventory-movements/export` con Excel para resumen y detalle.
3. Frontend: Selector de modelo de salida, busqueda por producto/SKU y tabla con columnas segun el modelo.
